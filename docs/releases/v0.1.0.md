# KytyPS5 Plus — Android v0.1.0

Initial Android release featuring **FEX x86-64 CPU translation**, **native Vulkan rendering** and a landscape interface designed for mobile devices.

- Astro Bot `no-rt` compatibility preset for PPSA21564 v01.007.000.
- Per-game resolution, render scale, GPU driver and GPU Turbo settings.
- Bundled Mainline Turnip V32, with driver ZIP import and online downloads.
- Customizable touch controls and physical controller support.
- Full, compact and minimal performance HUD modes.
- Folder-based game library and a scrollable in-game menu with edge-swipe access.
- Diagnostic ZIP export and a one-time storage permission request on first opening.

**Requirements:** Android 12+, ARM64 and a compatible Vulkan GPU. Game compatibility and performance vary; `no-rt` changes lighting and does not guarantee full compatibility. No game files included.
